# Poseydon Sublimação

Site estático, sem build. Publicado via GitHub Pages em https://poseydon.com.br

| Caminho | O que é |
|---|---|
| `/` (`index.html`) | Landing page para clientes |
| `/gestao/` | Poseydon Hub: painel de gestão (vendas, redes, estratégia, agentes, marca) |
| `logo.svg` | Tridente em platina |

## Configurar a landing page
No fim de `index.html`, no bloco **CONFIGURAÇÃO**:
- `WHATSAPP`: número com DDI e DDD, só dígitos (ex.: `5511999999999`)
- `INSTAGRAM`: link do perfil
- `PRODUTOS`: nomes e preços "a partir de"

## Hub de gestão
Os dados ficam salvos no navegador de quem usa. Faça backup pela aba **Dados**.
